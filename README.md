# living-data

**Data has always been passive. Code has always been active. This project questions whether that's a law — or just the first architecture we built and never replaced.**

`living-data` is a foundational research project to define, construct, and implement a new class of computational primitives — behaviors that give data intrinsic properties: existence, epistemic state, and temporal orientation — independent of storage, networking, or external code.

---

## What This Is Not

- Not a framework
- Not a library
- Not a new database paradigm
- Not a feature set

## What This Is

A new **ontology of data**. A serious attempt to replace the passive-data assumption at the root of every software system ever built.
